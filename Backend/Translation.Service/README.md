# Translation.Service

## Overview
Business logic layer for translation features. It implements application services that enforce rules, coordinate workflows, and communicate with the data layer.

## Responsibilities
- Validate inputs and enforce business rules.
- Orchestrate repository calls for translation workflows.
- Provide application-level responses and DTOs for the API layer.

## Key Components
- Service interfaces in `Interfaces/`
- Service implementations in `Services/`
