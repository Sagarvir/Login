# Translation.Contracts

## Overview
DTOs and contracts used to communicate between layers and across API boundaries. This project keeps request and response shapes stable and decoupled from entity models.

## Responsibilities
- Define request and response DTOs for API/service interactions.
- Provide shared contracts between the API and service layers.

## Structure
- `DTO/` contains request/response models grouped by feature.

## Usage
- Referenced by Translation.API and Translation.Service.
